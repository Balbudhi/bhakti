# Automatic lexical producer witness

This is an unchanged DSAL Platts query response for वज्र, acquired for the private Bhakti lexical investigation. `acquisition.json` records its query URL and exact SHA-256. The parser derives the complete original entry, including vajra / bajr / bajar and embedded compounds, from that response; tests do not fabricate dictionary content.

Source: John T. Platts, *A Dictionary of Urdu, Classical Hindi, and English* (1884), digitized by the University of Chicago's Digital Dictionaries of South Asia. The site describes its digitization as CC BY-NC-ND 2.0; this retained witness is unmodified and used as a private parser/attribution fixture. It is not public song-page copy.

The one-word वज्र test is a structural delivery fixture, not a claimed public song transcription or linguistic qualification. English definitions come from the separately attributed actual WordNet fixtures under `../lexical_support`.
