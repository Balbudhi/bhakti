# Main reader lexical realization regression

The JSON preserves three actual writer decisions, their selected source records, all candidate alternatives and cited English definitions. Original artifact SHA256 values are recorded in `provenance`; private file paths and raw provider/witness bodies are excluded. These are validation regressions, not editorial approval of the model output.

English definitions are WordNet3.1 excerpts, Copyright2011 Princeton University; the complete original license from the acquired data file accompanies this fixture in WORDNET-LICENSE.txt. Source dictionary identifiers/URLs and quoted meanings remain in their evidence records. Original paid requests are not replayed by these tests.
