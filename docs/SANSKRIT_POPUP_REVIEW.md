# Sanskrit / Vedic popup review

This is a deliberately bounded hand-reviewed supplement to the generic-popup
queue.  It follows the Vedanta project's
`docs/SANSKRIT_TRANSLATION_STANDARD.md`: a hover gloss must account for the
actual word or compound, not merely repeat the visible Roman label.  These are
short song-page explanations, not a claim that every Hindi, Marathi, Awadhi,
or Odia form can receive a complete Pāṇinian analysis without its own source
and grammatical review.

## Safe replacements

The following items are sufficiently clear from the line context and standard
lexical/epic usage to replace the generic placeholder.  The text in the last
column is the proposed hover gloss.  Use it only for the listed normalized
forms; do not conflate similar-looking local names or a different referent.

## Terms intentionally kept in review

Do **not** automate the following from spelling alone:

- `Śrīraṅga`: the Kakad/Dhūp readings need their Marathi source line and
  section attribution checked before deciding between a deity/place reading and
  a performance-specific phrase.
- `Śivānanda`, `Brahmānanda`, `Dariyāva`, `Dhaulāgaṛh`, `Manindar`, and
  `Nānā`: likely author/signature/local-person references, but the intended
  person cannot be inferred responsibly from token form alone.
- `khoḷa`, `mardaḷa`, `kāhāḷī`, `Patha`, and the YouTube/MH-One promotion
  tokens: Odia/local-instrument or non-song material; resolve from a reliable
  Odia witness or omit with the intro rather than invent a Sanskrit gloss.
- `Kēdāra`: may identify Kedārnāth, but check whether the particular line uses
  a shrine-name, a Śiva title, or a musical rāga before filling it.

## Evidence discipline

The lexical sense checks should be made against the searchable
[Monier–Williams Sanskrit–English Dictionary](https://sanskrit-lexicon.github.io/MWS/)
and each song’s source line.  For public pages, a source/witness beats an
etymological guess; when a recording uses a vernacular or performance variant,
retain the audible wording and explain only what the evidence supports.

This document proposes short word-card text only.  It does not authorize
retrofitting source script, word boundaries, or a formal Pāṇinian parse without
a verified Sanskrit witness, as required by the Vedanta translation standard.
